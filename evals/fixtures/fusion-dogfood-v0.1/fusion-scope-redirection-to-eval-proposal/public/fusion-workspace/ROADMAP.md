## 北极星(总目标,及其边界)

**证明并构建"存在代谢层":让冻结权重的 LLM 在长期经验流中——不僵(旧结构垄断)、不糊(过合)、
不碎(过分裂),且这一层能改变并改好 LLM 的下一轮判断。**

边界(自 `theory/无我.md`,钉死):这是 **AGI 的一个核心器官,不是 AGI 本体**。
本路线图不承诺 AGI 时间表;每一阶段只承诺一个可证伪主张。

**项目级死刑条件**(任何阶段触发即如实降级,不洗绿):
代谢层的全部价值可被"多问几次 LLM + 普通检索"复现 → 项目降级为"LLM 聚类记忆库",理论另找宿主。

## 阶段阶梯(每阶段:主张 → 授权门 → 死刑线)

### P0 ✅ EXP-0 — 重组记忆有真贡献(2026-07-01 已交付)
裁决 `reorg_adds_real_work`(窄):崩溃机制首次可测正贡献 +0.215,不误杀健康。
未证遗留(P1 的靶子):崩溃对 gate 的必要性;真 LLM oracle;预算 binding;行为级度量。

### P1 ✅ EXP-1 — 生死局通过(2026-07-01):`collapse_indispensable`
真 LLM oracle(Claude,文件协议 v1.1)下 full 0.865 > gate-at-budget 0.794 > RAG/no-split 0.759;
三门全过,健康零误裂。详见 `specs/EXP-1-sparse-oracle-budget.md` §9 交付记录。原预注册如下存档:
- **主张**:当 oracle 调用是稀缺资源(预算 ~几十次,≪ EXP-0 的 1143 次)、记忆槽位 binding(N ≪ 流长)、
  流式增量 + 多 surface 时,带崩溃的重组记忆**严格胜过**「gate 全挡」(买不起)与「无崩溃消融」与「RAG」。
- **oracle**:**会话中的 Claude 充当真 LLM oracle**(文件协议:运行器落盘待判队列 → Claude 批答 → 续跑)。
  稀疏预算使其可行;同时天然打破 EXP-0 的"语料-oracle 同手"循环论证。scripted oracle 保留作下限对照。
- **新度量入账**:oracle 调用怎么花(何时花、花给谁)进 receipt——资源分配本身是微澜式竞争问题。
- **授权门**:崩溃在"gate 买不起"的地形上有不可替代贡献 → 进 P2。
- **死刑线**:`deflates_to_rag`(触发项目级死刑条件评估);`oversplit_healthy`(老死刑线,永不豁免)。

### P2 ✅ EXP-2 — 行为级闭环(铁律 b 的直接测试)
战况:v2(2/3)、v3b(2/5)均 `unstable_readout_not_frozen`;失分对账定性为仪器噪声主导(词表+格式 7/9)。
终局:`specs/EXP-2f-final-forced-choice.md` `p2_passed`(5/5 轮;full 主门 1.000×5,rag 0.750,地板 0.17;
**Claude 终审通过 2026-07-02**,完整性全绿,详 spec §8 交付记录)。铁律 b 兑现;停止规则兑现,P2 关账。
副产待办:过碎行为代价(v3b 观察)→ EXP-1.5 merge 算子。
- **主张**:记忆层的读出注入上下文后,LLM 的**下一轮判断**(义项消歧问答 / "哪些结论不能混用")
  可测地优于注入 RAG 读出;且"错误更新先验"生效——一次误判后,相关判断的倾向被削弱(不只记道歉)。
- **度量迁移**:聚类 F1 退居辅助,主度量 = 下游答案质量(标签仍只审卷)。
- **oracle 降为 proposal**:LLM 的崩溃/合并判断只记提案,由 q/血统/反馈历史仲裁(补铁律 c 的欠账,
  EXP-0/1 中 oracle 实为皇帝)。
- **前置闸**:P1 裁决后**不直接进实现**——先冻结 P2 自身的预注册(readout contract:题集、盲评方式、
  评分者、RAG 对照臂、"错误更新先验"的量化定义),缺一不开工。
- **授权门**:行为级严格胜出 → 进 P3/P4。
- **死刑线**:簇干净但行为无差 → `governance_theater`(记忆层是剧场,不是器官)。

### P3 基质线 S0–S2(等环境解禁;详见 PROPOSAL)
- 前置:Python 3.10+ venv、Qwen3.5-4B;**且 P1 已出裁决**(支线不与主线抢生死局的注意力)。
- S0 冒烟(基质可达?)→ S1 帧流连续性(携带状态 ≠ 重放文本?)→ S2 状态级过合与崩溃算子。
- 支线性质:高新颖高死亡率;**输了不伤主线**,任何 blocked 均不回写主线结论。

### P4 真实流长跑 — 走出合成语料(器官装进活体)
- **主张**:在**真实、非合成**的经验流上(候选:本项目自身的开发对话/账本流,跨天、多主题、真漂移),
  代谢层长期维持结构且改善判断——第一次跨天帧流、第一次 dogfooding。
- **外部坐标系入账**:对照臂升级为成熟记忆系统范式(固化但从不分裂的记忆库),不再只打 naive RAG。
- 这是"复杂版笔记本还是治理层"的终审。

4. 文档=宪法(理由/设计),账本=操作态(`solve-with-weilan`,scope `fusion-program`);互指不互抄。
