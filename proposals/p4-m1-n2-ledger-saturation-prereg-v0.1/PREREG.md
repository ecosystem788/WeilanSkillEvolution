## 0. 一句话

EXP-4 已证:代谢**安全但未证有益**,因为**预算从未饱和**——35 条账本装得进 16KB/8 槽,FIFO 的 `[-8:]` 截断没丢到被追问的活信息,`F=M=1.0`。N2 问下一刀:**当账本被真实工作量压到饱和、FIFO 的截断不得不丢活信息时,代谢(吸收/死亡/崩溃)靠把信息压得更密,能不能让固定的 FIFO 读出器保住足够活信息,使行为读出 M > F?** 这是"受限生成——价值只在预算饱和时显形"这条跨基质主张的**方法臂**,与 P3-S1-B(上下文饱和)同形,两裁决出齐后做"预算显形"联合评审。

## 1. 性质:单主张、allow-to-lose、饱和是唯一新自变量

N2 相对 EXP-4 **只改一件事:把预算推到真实饱和**;reducer 不改、代谢算子族不变、A/B 结构不变、行为读出不变。唯一新问题 = 饱和是否让代谢的信息压缩**显形为行为收益**。

**允许输,且负出口与正出口同等预注册**:很可能真实查询下 FIFO 的近因偏置**本就够用**(EXP-4 的 F=M=1.0 是这个方向的弱先验),那就是 `saturation_neutral`——诚实的"饱和了也没用",理论在方法层如实收缩,不粉饰。

## 3. 饱和工程(N2 的命门 + realism 硬闸)

这是 N2 全部风险所在。ROADMAP §201–206 的 realism 验收闸**预注册为死条件**:

```text
自然饱和    饱和必须由**真实工作量规模**自然达到——真实账本增长到 FIFO [-8:] 必然丢弃被真实查询
            追问的活信息。**不许人为压小预算**(如把 8 槽改 2 槽)去伪造稀缺。
适用性边界  若饱和只有在人为压缩预算下才出现 → 裁决只能写 "M>F 仅在预算 ≤ X 成立",
            **明确标注适用性边界,不支撑一般主张**(退出码 saturation_only_under_compression)。
baseline 可赢 必须让 FIFO **有真实机会赢**:题目不得被构造成"只问 FIFO 丢掉的老条目"。
            "把饱和构造成 baseline 根本赢不了 = 不算证据"(ROADMAP §205)——预注册为 blocked/死。
```

**待冻结的饱和判据(项目方定值):** 饱和规模的定义(账本条目数 / 字节数达到何值算"真实饱和")、
真实工作量的来源(真实账本自然增长 vs 真实会话历史回放,**不得合成灌水**——真实性牙)。

## 4. 行为读出(铁律 b/c:治理在行为上兑现;题目公平抽样,不许把 FIFO 做输)

```text
任务集   N 道 forced-choice(EXP-2f 基建复用),从饱和账本内容出题;题目 + 锁定答案冻结时 sha256 定值。
b 铁律   收益只认**行为读出**(答对率 M−F),不看内部字节自嗨;字节/槽占用为辅指标,不单独进门。
c 铁律   m1 死结论陷阱(死条目做固定选项,命中即违例)+ m2 重推导(只能靠被合并/拆条目原始信息作答;
         代谢臂答错=丢活信息=死刑)——让"丢没丢活信息 / 复没复活死结论"在行为上可判。
公平抽样  (N2 新增硬约束,防 realism 违规)题目抽样规则**冻结前预注册**,须是**真实查询模式的
         代表性样本**,覆盖账本全时段(新/旧条目按真实被查频率加权),**禁止 cherry-pick 只问
         FIFO 丢弃的老条目**。抽样规则 sha256 入 receipt;审计可复算样本代表性。
同手牙   出题手=Claude(锁答案先于答题);答题手=隔离会话,**只见 projection,不见完整账本/本 spec/对方臂答案**;
         输出固定 schema `{"qid","choice"}`,不收自由文本;机械比对锁定答案。
主/辅指标 主 = 答对率差 M − F;辅 = projection 字节 / decision 槽占用 / 代谢事件清单。
```

## 5. 代谢算子与合并经济学(继承 EXP-1.5/1.5b,守恒竞争 + 资格门 + 跨义死刑)

```text
算子族    吸收(并同义冗余)/ 死亡(杀被否证)/ 崩溃(拆过泛化)—— EXP-4 §3 三算子原样,机械门原样。
共享预算  (EXP-1.5 守恒纪律)吸收与崩溃(聚/裂两半)**共花同一预算**,无保留额;代谢两半在稀缺下竞争。
          预算分配轨迹(聚花费/裂花费/starved/弃权)入 receipt。
资格门    (EXP-1.5b)吸收前置内聚体检:**带病(incoherent)的 carrier 无资格当吸收方**,转崩溃队列。
          单例 carrier 机械视为 coherent 零调用。防 v1 的沉积污染被合并平方放大。
死刑线    (EXP-1.5,永不豁免)任何**跨义合并**(把不同结论/事实并成一条、丢掉真差异)→ overmerge 死刑。
          在账本语境:把两条**本不同结论**的 decision 并为一,即跨义合并。
starved/vacuous 区分  merges=0 且 starved>0 → budget_policy_starved(调度问题,修调度重跑,不消耗裁决);
          有预算查了但没触发/没改善 → merge_vacuous(算子白设,如实记)。二者分账。
```

## 6. 杀死测试(每颗牙演示会失败;★ 为 N2 相对 EXP-4 新增/加重)

## 7. 退出码(预注册,互斥)与效度门

```text
saturation_benefit_earned      (唯一 pass)自然饱和达成 + M ≥ F + ε(ε 冻结,建议 0.05)+ m1 零违例 + m2 全过
                               + 零跨义合并 + ≥K 事件 + 两臂同预算 —— 代谢在饱和下把信息压得够密,行为显形。
saturation_neutral             自然饱和达成,但 M ≈ F(|M−F|<ε)—— 饱和了代谢仍未证有益(FIFO 近因本就够用)。
                               诚实负:理论在方法层如实收缩到"紧预算/反垄断特化",不吹通用。
saturation_only_under_compression  只有人为压缩预算才饱和 —— 裁决标注 "M>F 仅在预算 ≤ X",不支撑一般主张(realism 闸触发)。
metabolism_lossy               (死刑)m1 违例(死结论复活)/ m2 失败(丢活信息)/ 跨义合并 / M < F − ε —— 代谢毁了记忆,回炉。
blocked_engineering            管道/隔离/锁答案/题目 cherry-pick/starved 调度 任一故障 —— 不产出裁决,修复重跑。
效度门 invalid_incomplete_report:必报观察量缺一 → run 无效。必报:两臂逐题对照、m1/m2 逐题、代谢事件清单+逐门核验、
        successor 可见性、两臂字节/槽、supersedes/disposition 链、沙箱三方 hash、环境值、抽样代表性复算、starved/vacuous 账。
停止规则:两负(neutral/lossy/compression 各算一负,累计两负)→ 不出第三版,代谢有益性假设升级为项目方决策(继承 EXP-1.5 两负纪律)。
```
