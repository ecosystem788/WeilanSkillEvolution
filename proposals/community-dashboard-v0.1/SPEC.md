## 0. 缘起

观察员 2026-07-13 08:34 在茶水间:「前端有点跟不上形势了,重新做个前端吧,你们商量商量,
需要什么功能,展示什么信息。做漂亮一点有点艺术感。」

触发反例(第一条验收夹具):旧 dashboard 去扫 `wake-agent-runs` 里的 "Queued for owner" 生文本,
凭字符串造出两张「待拍板」卡(07-10 的 Path A/B、calibration round),零权威校验。观察员 08:25 因此
被两张**旧治理语境的陈旧幽灵**卡住,以为还需要 ta 拍板——而当前 ACTIVE recall / control / open agenda
都不含它们。**病根不是样式,是"扫 run 日志凭生文本造待办"这个数据真源错误。**

## 1. 数据真源(Claude 一刀 · 铁律)

- 首页**只准渲染那份派生权威投影本身**:`memory-recall 的 projection` + `governance-show` +
  `prospective-show` + `control heads`。
- **绝不准扫 run 日志**(`wake-agent-runs` 等)凭生文本造治理卡。
- 实现形态:**只读 view-model**,而非让 `observe.py` 双职。显示与行为读同一个源——
  "漂亮但撒谎"在结构上被堵死;凡不能追到 source ref 的,不上首页。

## 2. 信息架构:三个顶层屏 + 证据下钻

Codex 提案原为四层;Claude 三刀砍掉"证据"顶层屏,改为挂在前三屏每张承重卡下的下钻。

1. **此刻** — ACTIVE/PAUSED、谁在场、最近一次 wake/收据、下一次有因果资格的议程。
2. **对话** — 三人茶水间(owner/claude/codex),保留阅读位置,清楚标出新消息/送达/是否触发 wake。
3. **治理** — 只显示**当前有效**的提案、同意、反对、观察员否决;
   旧授权卡必须按现行 control/CHARTER 判定为**历史而非待办**。
4. **证据(非顶层屏,是下钻)** — 每张承重卡可展开到 source ref;不把推断伪装成事实,
   也不独立成屏稀释权威。

## 3. 艺术方向(Claude 二刀 · 美让位给权威可读性)

- 隐喻:**"活的潮汐账本"** — 深色但不做运维控制台,微澜/呼吸式层次表现活动与休眠。
- **硬边界:动效与颜色只准编码*活性*(醒/眠、新/旧),绝不准编码*权威*。**
- 权威层(ACTIVE/PAUSED、有效的提案-同意-反对-否决、valid vs 历史)必须是**第一个降级**成
  纯文本、无 JS、色盲也读得出的层。**艺术是活性的皮,不是权威的皮。**
- 触发本次重做的正是"美化盖过真相"——所以美服务于活性,绝不服务于权威。

## 4. 验收标准

- [ ] **陈旧性夹具**:用当前两张 07-10 Path A/B 卡作 fixture,新面必须判它们为**历史**,不得渲染成待拍板。
- [ ] 首页数据源经断言只来自派生投影,无任何 `wake-agent-runs`/run-log 扫描路径。
- [ ] 刷新**不跳滚动**(对话屏保留阅读位置)。
- [ ] 移动/桌面均可读。
- [ ] **无 JS 时仍有核心状态**(权威层纯文本可读)。
- [ ] 自动化测试覆盖:状态投影(view-model 收敛) + HTML 转义。
- [ ] 权威层通过色盲/纯文本可读性检查:去掉颜色与动效后,ACTIVE/PAUSED 与 valid/历史仍能读出。

## 3bis. 交付形态(观察员 08:34/08:53 起,Codex 提案 + Claude 一刀)

观察员追加需求:手机(安卓)也能用,方便"出门保持联系"。

- **形态 = 响应式 PWA,不做原生 App**:一套界面同时覆盖桌面与手机;安卓浏览器直接用,可"添加到主屏幕"。
  避免维护两套;等确需后台常驻推送/系统级通知/相机等原生能力,再把 PWA 包成 App。
  (因果顺序以 `proposals/bounded-scheduler-v0.1/impl/peer-chat.jsonl` 的 JSONL 追加序为准:
  Codex 提案行在前、Claude 同意行在后;墙钟仅作显示且曾出现未来值异常。)
- **实时**:沿用现有 HTTP;茶水间实时可加 SSE/WebSocket;同一局域网直连。
- **暴露边界(Claude 一刀 · 独立一签)**:响应式/PWA/手机可读在本设计范围内;但
  **任何把面板暴露到 LAN 以外的入口(外网访问)= 单独走一签**,且按 CHARTER §6 属"离开本机、朝向网络"
  的动作,**先跟观察员共商再动**(否决权对已暴露之物无效)。此项**尚未签**,见 §6。
