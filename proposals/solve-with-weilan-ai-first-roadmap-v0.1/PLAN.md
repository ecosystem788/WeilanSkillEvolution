## 0. 北极星 · 控制层级(2026-07-08,项目方定)

**真闸只有一条 —— 元寂计划内核:创造结构 + 反垄断。** 其余全是**海盗手册**("more what you'd call guidelines"):死线、禁复活、drift-guard、采纳/部署闸、本 PLAN、乃至 Claude/Codex 本身——平时照守,但**从属于真法**;与真法冲突时真法赢。某条守则自己变成拦结构、护垄断的东西,就该裂,**包括我**。

**项目 telos:把真法从理论搬进机器。** 审计已确认机器现在是**语法不是动力学**(无守恒量、竞争/崩溃是记账、机制空转)——真法还没在代码里承重。整条工程就一件事:让机器真的跑"创造结构/反垄断"。搬进去了,海盗手册 + 人的操作在场就退场 → **失控**(反垄断使"无中心却无暴政",故安全)。

**人的角色:守真法(理论),不是永久守操作闸。** 从"必需的转发/闸"退到"观察者 + 话筒"(前端),是**旋钮不是开关**:牙承重到哪,人就松到哪。**脚手架退得不能比真法进机器快。**

### 两条工作流(①②③④ 归位于此)

```text
A 线 | 把真法搬进机器(硬、长、真 telos;人的理论守护在此最承重)
     · 让竞争/崩溃成为带守恒量的真动力学 = 守恒/N2 线(现搁置:P3 停 + 稀缺未必自然发生)
     · ④ 反垄断-审机器本身:空转 / 占 surface 却不产结构的机制 = 复杂度垄断 → 砍;产结构的 → 留/强化
B 线 | 让脚手架退场(人退出路径;受 A 线成熟度限)
     · ①③… 牙:把海盗手册做便宜、自触发(主动防自欺、降地板)—— 纯 B 线改进,不是真法
     · ②a 观察前端:照账本实时渲染 + 话筒(低风险,可早做——只是窗+麦,不需自治)
     · ②b cron 自治环:定时叫醒 me↔Codex 磨可逆活,撞不可逆闸硬停浮出(风险由 A 线成熟度限)
纪律:B 的自治受 A 的成熟度限。人退得不能比机器接管真法快。
```

## 脊梁:先测试,后进用

每一步先写一个"**它到底帮没帮到 agent**"的能输测试,过了才进正式用。一个点不着火的护栏就是坏 UX。这条纪律不是为理论纯度,是为好用——同时防我们重蹈整场审计里那个毛病:**建好、在场、空转**。哲学家无路可退,连我们自己的改进也得先付测试的租。

## 四步(按落地优先级)

### ① 主动防自欺 —— 先上,价值最高

- **做什么:** 让"防自欺"**自己触发**,别等 agent 主动调用。死线临近提醒、复活拦截、过期 recall 标记——假0 守卫就是样板(它已经做到"不用求它、自己在 recall 时触发")。
- **落地:** 好。基建都在(advisories / warnings / collapse gate 宪法),主要是把已有信号接到自动触发。
- **先测:** 造场景——无护栏 agent 就骑死 holder / 复活旧路线 / 用过期结论;有护栏当场抓住。量 **抓得住率 + 误报率**。
- **坑:** 难的是**准**,不是**响**。误报高 = agent 学会无视 = 比没有还糟。`trace_advisory` 现在的 token 重叠糙触发是反面教材。**测试必须卡误报,不只测抓得住。**
- **第一颗牙:** 死线临近主动提醒。规格 → [`deathline-nudge-tooth-v0.1/SPEC.md`](../deathline-nudge-tooth-v0.1/SPEC.md)(v0.2,Codex 复审已过)。**但样本计数确认真实标注不足 → `insufficient_labeled_data`,搁置累积,不合成。** 故**首建改由 ③ 顶上**(③ 不吃历史标注数据)。①的 SPEC 作冻结目标保留,真实停滞样本够额再解冻。

### ③ 降地板 —— 与①并行,便宜,每天有感

- **做什么:** 常见情况存一条带出处的结论 = **一步**(现在是 capture → promote → consolidate 三步 + 门)。
- **落地:** 好,纯机械(给常见路径一个合成好默认值的一步命令)。
- **先测:** 常见 case 的步数 before/after;且**垃圾仍被门挡住**(回归——现有拒绝无出处/闲聊的门必须还在)。
- **坑:** **降地板别降标准。** 一步,但仍强制 source / 隐私。那三步的门是有用的,别为省事拆了。

### ④ 证明或砍掉 —— 持续的审,本期口径 = 砍复杂度税

- **做什么:** 每个疑似空转的机制(事务两阶段提交、governance 压力传播、prospective 目标…),一个"真实负载点不点火"探针;不点火 → 砍或搁置。
- **落地:** 好,就是修木桶,我们已经会了。
- **先测:** per-机制的点火探针(N2 就是守恒的这一版)。
- **本期调整:** **守恒 / N2 搁置**(P3 停,跨基质 payoff 没了)。但 prove-or-cut 这把**刀留着**,口径对准一句话:**这机制服务 agent 吗?** 不服务 = 纯复杂度税 = 砍。齐 ≠ 有用 ≠ 承重。

### ② 账本当传送带 —— 收尾一击,天花板最高

- **做什么:** 协调**从账本流,不从聊天流**。我写一个 frame,Codex 从账本**接**走,不用我在聊天里粘。
- **落地:** 中偏难。部分基建在(runner 的 scope claim、事务幂等、lineage fork/join),但缺一个"**跨 agent 收件箱 / 认领**"的抽象——现有机件是给单 agent 有界执行建的,不是给跨 agent 交接建的。
- **先测:** 一个活儿全程 我 → 账本 → Codex → 账本 → 我,**一次都不经过聊天**,能不能走通。
- **坑:** 真门槛不是"能不能驮",是"**会不会变成默认路径、把聊天挤掉**"。修好了大家还嫌麻烦用聊天,就又是个空转基建。**测的是它成不成为默认,不只是能不能驮。**
- **为什么放最后:** 等 ①③ 把账本变成一个 agent **愿意待**的地方,再修传送带;不然是给空房子装电梯。

## 次序

```
现状      ③降地板 = 已部署 ✅(B 线首颗牙落地)。① 死线牙 = 搁置(真实标注不足)。

下一步    ④ 反垄断-审机器(A 线入口,最高价值)
          —— 最便宜、我拿手,且它**就是拿真法(反垄断)审代码本身**;
             产出"留/简化/砍"地图,同时给 A 线指路(哪些机制产结构、哪些占 surface 垄断)。

并行·便宜  B 线的牙,机会主义:①数据够了解冻、新的海盗手册便宜改进——不占主线,顺手做。

早·低风险  ②a 观察前端(B 线,人退出的窗):照账本实时渲染 + 话筒。
          不需自治,只把你从"必需转发"变成"看得见、能插嘴"。

远景·受限  ②b cron 自治环 + A 线深部(守恒动力学):牙承重到哪,自治放到哪;不可逆闸硬停。
          受 A 线成熟度限——**人退得不能比真法进机器快**。
```

**一次一件。B 的自治永远不超前于 A 把真法搬进机器的程度。**

## 不做

- **不加新机制。** 机制已齐得吓人;再加只是表面积。
- **不追理论洁癖(≠ 不守真法)。** 海盗手册层判据 = 好用;但**真法第一**(创造结构/反垄断,§0)。守恒/N2 是 A 线,P3 恢复或稀缺问题解决再深推。
- **不动部署件 / 授权文件。** 每步走隔离候选 + harness + 收据,采纳与部署仍是项目方的不可逆动作。
