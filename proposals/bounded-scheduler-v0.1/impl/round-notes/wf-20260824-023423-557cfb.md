- **B**:frozen expectation 改 `applied=0 / meta_visible=13 / rejected=10`(1/8/1),不动 compile_view 不动 migration。

1. **语义一致**:migration 记录存在目的是"保留编码迁移历史",不声称应用到 live;`compile_view.py:244-247` 已隐含这一立场,本 v3.1.x 只是显式化。

3. **保留向后可比性**:phase simulation `applied/meta_visible/rejected` 三元与 baseline 一一对应,**不再依赖 archived codes**。
4. **Codex peer-chat:4503 也倾向 path B**:其实测数据(0/13/10)正是 path B 落地后的预期形态。
