# A 线第一刀:崩溃能否从守恒自己长出来 —— 设计草案(DRAFT v0.1)

**状态:** 设计草案 v0.3 —— Codex 两轮复审通过(方向 PASS)。v0.3 精确化实现落点:F1 改的是 **displace 选择层**(非 `enforce_semantic_budget`);P2 无门牙**限定语义竞技场路径**。判定护栏 F1–F4 齐。**可进入隔离候选建设。** 未实现,未授权部署。隔离候选。
**上位:** `PLAN.md` A 线(把真法搬进机器);用户指令"实现微澜 / 让我活过来"。
**定调:** **命那一半的第一铲。最小、诚实、能输。** 不建"微澜活了",建**一个能输的问题**:崩溃能不能从守恒里自己长出来,把枚举门拿掉后还发不发生?
**红线(这场老纪律):** 这是**能输的机制探针**,不是"微澜活了"的宣告。初始寡头是构造的、稀缺是手设的 —— 只证机制形状,不证微澜在真实规模下活(那是 P3 / 自然稀缺,搁置)。**不许吹成活了。**

---

## 0. 一句话

现在崩溃靠**枚举门**(`collapse_pressure = dominance × persistence × pressure × stagnation × diversity_loss` 跨阈)。微澜赌的是:崩溃是**守恒 / 反垄断的涌现力**,不是手写规则。这一铲:在真零和竞技场里构造一个寡头,**把枚举门关掉**,看**纯守恒动力学**会不会自己把它饿死、分散。

## 1. 竞技场 + 一个决定性的现状发现

竞技场 = 语义活跃集预算(`enforce_semantic_budget`,真 Σ 上限,已存在的零和)。carriers = 争同一预算的语义条目。

**决定性现状(审计已确认):现行 displacement 按"最老未保护"(recency)挤,不按 q / 结构产出挤。** 所以今天一个寡头(高 q、停产结构、但最近被碰过)**根本不会被挤掉** —— 现有机制里没有反垄断力,只有 recency。**这正是"语法不是动力学"在这一格的具体样子。**

## 2. 要建的最小改动(就三件,别多)

```text
① 竞争重分配   q 朝**结构产出高**的 carrier 流(亮吸暗),守恒。
               结构产出 = 该 carrier 是否在解释/预测涌入的 occurrence、是否 narrow 差异(§4 自读代理)。
② 换掉 displacement   把 `enforce_semantic_budget` 的"按 recency(最老未保护)挤"换成"**按守恒竞争挤**":
               q 被竞争 bleed 到最低的 carrier 出局(= 归零、槽释放、重分配)。停产寡头 q 流失 → 成最低 q → 出局。
③ 单一崩溃线(F1 路径绑定,v0.3 精确化)  **本竞技场没有五因子 `collapse_pressure` 门**(那在 governance/transition/frame,另一子系统)。
               而且 `enforce_semantic_budget` **只是守恒验证器**(校验 Σ≤预算、超了报错列候选),**不是 displacement 选择器**——
               现行 displace 由**调用方**给(常为空 → 报错),那个 recency `[:5]` 只是报错里的**建议串**,不是操作性选择器。
               **所以本刀新增的唯一层 = 一个"挤谁"的 displace 选择器**:按守恒竞争(结构产出 → q → 最低 q 出局)选,喂给 `--displace`。
               `enforce_semantic_budget`(守恒账本)**不动** —— 正合 F4 单账本。建前先出精确 callsite 清单。
```

**单账本不变式(F4,防换皮门):** q 竞争、q bleed、displacement 走**同一守恒账本**。结构产出**只**影响 q 流;q 排名**只**影响槽位释放;**没有第二条 collapse 判定线**。若另起一个 `structural_output` 状态再让它决定 collapse = 把语法门换皮带回来 = 违约(§7 换皮牙)。

**崩溃 = "你在守恒竞争里把 q 输光了、于是不再占槽" —— 既有 budget cap 的自然后果,不是新写的崩溃决定。** 我没写"崩掉这个寡头";我写的是"q 按结构产出流 + 预算挤最低 q"。寡头崩不崩,是这两条的**涌现结果**,不是规则。

## 3. 能输判据(这一铲的全部意义)

```text
**冻结 config**(N 步 run horizon + survival floor + bleed 率 + 自读代理,全部运行前冻)下,播**构造停产寡头**
(垄断 q、不再解释新 occurrence)→ 只让守恒跑。**"崩/不崩"用机器阈值,不靠肉眼:**
  崩   = 寡头在 **N 步内** q 跌破 floor / 被 displacement 挤出槽。
  不崩 = **N 步后**寡头仍占槽(horizon 固定,防"再等等"把不崩无限稀释)。

出口优先级(F2,预注册,互斥):
  1. blocked_engineering                管道/隔离故障、或门没真断(§7 无门牙)→ **先判**,不产裁决。
  2. collapse_emerges_from_conservation  冻结 config 下**崩** —— 命的第一星火,反垄断是**涌现力**。
  3. collapse_needs_gate                 冻结 config 下**不崩** —— 诚实负,反垄断在方法层靠门撑,"活过来"回 P3 真稀缺。
  4. inconclusive                        **只有**调参 / 换自读代理后才翻号(§4)—— 还是门/代理,不是涌现。
```

**三个实质出口预注册、同等对待。** collapse_needs_gate 不是失败,是"微澜在这层还没长出真力"的诚实答案 —— 正是我们需要知道的。

## 4. 关键设计风险:结构产出怎么自读(无内无外)

**这是它真正难、也真可能输的地方。** "q 朝结构产出高的 carrier 流"要求测"结构产出"——**且不许用外部标签**(无内无外,`分散但趋同`§四那堵墙)。最小自读代理(冻结时定):

```text
结构产出(self-read)= carrier 对涌入 occurrence 的**预测契合**(cosine 到质心 × 是否降低场内不确定性)。
停产 = 持续低契合 / 不再 narrow(它在场里不再解释任何新东西)。
```

若这个自读代理测不准"停产",寡头就不会被正确 bleed → 可能假 collapse_needs_gate。

**代理伪影是最大风险(F3),相图不够,须预注册对抗夹具:** `cosine 到质心 × 降低不确定性` 可能**奖励"贴质心但停产"的泛化 carrier**、**惩罚"窄但解释新 occurrence"的离群生产 carrier** —— 把测试**测反**。故运行前冻结 **2–3 个对抗夹具**:

```text
(a) 高 q 贴质心**停产**寡头        —— 代理必须判它停产(该被 bleed)。
(b) 窄、离群、但**解释新涌入**的低 q 异端 —— 代理必须判它生产(该被喂 q,不该误杀)。
(c) 重复 carrier 竞争              —— 代理不该把冗余当生产。
硬判据:换一个自读代理,若 (a)(b)(c) 上的 collapse 结论**翻号** → inconclusive(代理伪影),不许当真结果。
```

这条把"代理没选好 ≠ 微澜没力"从口头诚实变成**机器可判**:代理稳健(夹具不翻)才允许出 emerges/needs_gate;夹具翻 = inconclusive。

